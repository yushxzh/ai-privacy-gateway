# 0.1.4 实施与验收清单

本轮目标：WorkBuddy 按自定义 API 接入；内置模型不改动。凭据检测与个人信息规则可打开，每条规则可用内置样例或自定义内容验证。

## 设计

- 从 WorkBuddy 已保存的自定义模型文件识别来源，不限制服务商或模型前缀。每个模型单独启用、恢复直连；保留 Key 与无关配置。
- 本地仅保存原服务地址、恢复所需能力标记与本地连接凭据。模型 Key 仍由 WorkBuddy 管理，认证只随请求发送到该模型已配置的来源，不跟随跳转。
- 延续绿色桌面界面。左侧两个检测入口进入对应规则列表，选择规则后展示说明、覆盖边界、样例、输入与真实检测结果。批量验证使用同一检测引擎，不调用模型服务。
- 凭据默认阻断，个人信息默认替换。规则增加稳定 ID，检测、页面和样例使用同一目录；保留已有扩展接口。
- 助记词按 BIP39 字典及校验检测，另识别明确标注的助记词；不生成钱包或访问资产。

## 验收

- [x] 多个不同来源与模型名称可分别接入，内置条目不改动。
- [x] 重启、恢复直连、外部配置修改、无效配置、错误本地连接均有验证。
- [x] 认证不出现在页面、记录或本网关持久配置中；来源绑定、替换后外发、阻断不外发经真实 HTTP 测试验证。
- [x] 服务器私钥、云端/API 密钥、连接凭据、账号密码、OAuth Token、JWT、助记词、邮箱、手机号、身份证均有规则与正反例。
- [x] 两个检测入口可点击，每条规则可选、每个样例可运行，自定义内容与整组验证可用。
- [x] 检测页使用实际隐私流水线，纯本地验证不连接模型，不混入云端请求记录。
- [x] 桌面交互、键盘操作、长内容滚动和小窗口验证通过，截图留存。
- [x] 更新文档并启动最新 macOS 应用；保留 Windows 未真机验证的边界。

完整证据见 [验证记录](VALIDATION.md)。本轮已通过本地检查、桌面交互和真实 DeepSeek 文本请求；其他商业来源未逐家使用真实 Key 联调。
