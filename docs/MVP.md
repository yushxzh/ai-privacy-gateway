# AI Privacy Gateway · MVP 功能表

本项目面向个人开发者和技术团队，提供 Windows / macOS 本地桌面应用。启动应用后，客户端将模型 API 地址指向本机网关；网关在请求发送给模型服务前执行检测、策略判断和替换。当前交付是可运行的开发骨架，商业发布、完整编码 Agent 兼容和检测效果评测属于后续阶段。

0.1.6 的最新交付与实测见 [迭代记录](ITERATION-0.1.6.md)。WorkBuddy 原登录现已提供一键开启、原代理备份、重启和正常退出恢复。语义分类按本轮决定暂缓，Windows 真机验收未完成。

## 首版产品决策

- 应用关闭即停止网关，不隐式留在托盘。端口被占用时保留 GUI，并允许修改端口后重试。
- 默认使用「离线演示」上游，无需 API Key。演示通过真实本地 HTTP 网关产生请求和记录，不预填虚构统计数据。
- Codex / Claude Code 可启用「沿用客户端认证」，不在 App 再填写 Key。原认证只逐请求转发到固定官方地址；命令自动生成独立本地通行 Header。
- SDK 模式在设置中填写上游地址、模型和 API Key；配置和 Key 不写入文件。默认离线演示关闭原认证转发入口。
- 原始请求和替换后数据最多保留最近 100 条，总体设有内存上限；长记录保留开头与结尾，原文与替换预览各最多 24,000 个字符。记录列表默认不包含原文，选择记录后按需显示。
- 凭据与 PII 默认使用单请求代号替换；用户可逐规则改为阻断或关闭。检测是有限规则集，存在漏检和误报，不承诺「所有敏感信息都不会外发」。
- 非流式响应支持代号恢复。SSE 首版保持代号，避免跨分片恢复破坏事件与工具参数；界面和文档明确提示。流式恢复、跨请求会话映射另行实现。
- 仅接受文本请求。图片、音频、文件、加密内容及无法检查的协议字段明确拒绝；不作为未检查数据直接发出。
- Codex / Claude Code 接入命令只作用于当前终端，不覆盖现有客户端配置文件。WorkBuddy 按模型更新自定义 API URL 与能力标记，保留 Key 和其他配置。恢复信息保存在本机，关闭后恢复原配置；配置移除或改回直连时自动撤销入口。生成命令不等于自动执行，不等于完整客户端兼容性验证。

## 接入能力边界

| 客户端 | 本次提供 | 仍需验证 / 实现 |
| --- | --- | --- |
| Codex CLI | 独立自定义 Provider 的启动命令；Responses 文本接口 | 工具循环、多模态、WebSocket、会话状态、完整编码任务 |
| Claude Code | `ANTHROPIC_BASE_URL` / `ANTHROPIC_CUSTOM_HEADERS`；保留客户端原认证 | 工具循环、thinking、多模态、完整编码任务与账号政策 |
| WorkBuddy | 原登录 / Auto 的 HTTPS 文本替换、主动阻断及恢复已实测；亦保留自定义 API 入口 | 一键接入 / 停止与恢复、完整工具任务、流式恢复、跨请求映射 |
| ZCode / AutoClaw / TraeWork / CodeBuddy / TraeCode / OpenCode / OpenClaw | 原订阅入口证据与缺口清单 | 原会员 / 原认证转发实现、完整请求检查和逐客户端验收 |
| DeepSeek / OpenAI SDK | `OPENAI_BASE_URL` / `OPENAI_API_KEY` 与显式 SDK 示例 | 真实付费账户调用、各 Provider 特有字段 |

Codex 与 Claude Code 的实验模式复用请求中已经携带的原认证，不读取或迁移客户端凭据文件；真实订阅尚未联调。扩展方向已确定为优先保留各平台原有订阅和登录，自定义 API 不作为原会员适配完成的依据。详见[原订阅接入矩阵](SUBSCRIPTIONS.md)。客户端在本机网关之外的遥测、插件和工具网络请求不受本网关控制。

## 后续 MVP 迭代

1. 针对固定版本 Codex、Claude Code 建立真实客户端兼容用例，补齐工具参数、SSE 本地恢复与会话映射。

3. 增加用户主动开启的本地加密持久化，以系统密钥库保护数据；增加保留期限与删除功能。
4. 当前已完成逐规则动作配置；后续按实际需求补充例外与语义路由。
5. 完成 Windows 真机、macOS Intel / Apple Silicon 验证，以及安装包签名、公证和更新流程。

本次不包含企业控制台、账号、RBAC、浏览器插件、MCP 网关、OCR、自训练模型和正式安装包发布。项目源码采用 [MIT License](../LICENSE)。
