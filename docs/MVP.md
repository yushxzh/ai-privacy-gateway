# MVP 功能范围 · 0.1.7

本文只记录 0.1.7 的版本范围。完整产品需求、P0–P3 等级与后续验收以 [全局 PRD](PRD.md) 为准；操作见 [使用指南](USAGE.md)，开发命令见 [开发指南](DEVELOPMENT.md)。

## 当前交付

| 能力 | 已交付范围 | 限制 |
| --- | --- | --- |
| 桌面应用 | Electron + React + TypeScript；保护、记录、规则、设置；独立图标、融合标题栏和细滚动条 | macOS arm64 已实测；x64 运行时在 Rosetta 验证，Windows 实机后置 |
| WorkBuddy 一键接入 | 准备运行时、检查证书、备份原代理、重启生效、停止和正常退出恢复 | 原登录 / Auto 文本已实测；证书授权及撤销结果见 M1 记录，付费套餐不作声明 |
| 接入与证书移除 | 恢复原代理、精确撤销用户证书和删除私钥、失败重试；Windows 卸载前清理 | Windows 实机未验证；macOS 系统授权需人工完成 |
| 普通 API 网关 | 回环监听、鉴权、Chat Completions、Responses、Messages、count_tokens | 文本子集；没有 Embeddings、完整工具协议或任意协议互转 |
| WorkBuddy 自定义 API | 每模型独立启用、保留 Key 与来源、恢复直连 | DeepSeek 文本有真实验证；不作为原生会员适配证据 |
| 检测规则 | 10 条凭据与 4 条 PII 规则；默认全部替换 | 格式有限；姓名、地址、语义机密等未完整覆盖 |
| 策略与自定义规则 | 内置 / 自定义逐规则替换、阻断、关闭；固定文本 / 正则增删改与本地保存 | 没有自动模型路由、独立规则包更新或按客户端策略例外 |
| 请求记录 | 时间、来源、类型、动作、状态、命中规则与版本、原文 / 替换对照；原生外发正文校验 | 内存有界，原文默认隐藏，长预览截断；范围外流量最多 20 条；没有周期历史报告 |
| 替换与恢复 | 单请求内稳定代号，普通 API 非流式 JSON 可恢复 | 原生响应、SSE 恢复和跨请求映射未完成 |
| 原认证实验 | Codex / Claude Code 的原认证路由与 Bash / PowerShell 命令 | 只有模拟验证，不能用于宣称完整原订阅任务已支持 |
| 本地数据 | 原文记录 / 映射保存在内存，规则、代理恢复与 CA 保存在本机 | 网关不管理原客户端历史；未实现可选加密历史 |
| 扩展契约 | Secret、PII、Reversible、Policy、Provider Router、Semantic 六类接口 | Semantic 只有关闭实现；自动路由只有预留 |
| 开源与构建 | MIT 公开源码、第三方声明、依赖锁文件、macOS / Windows 构建配置 | 提供三个架构预览包；正式签名 / 公证和自动更新未完成 |

## 当前保留的边界

- 原生接入优先保留原登录、模型和权益；自定义 API 使用自己的认证及计费方式。
- 识别为敏感内容不等于必须阻断。默认替换，用户可修改；正常模型认证 Header 保持不变。
- 受保护的模型端点按协议检查，未知格式停止外发；其他端点和完整 Agent 工作流仍不属于全量保护。
- 页面中的候选客户端说明不代表已支持。其余七个客户端进入 PRD 的独立适配计划，Cursor 已取消。
- 语义分类保留为 P1 需求，按当前决定暂缓；接口预留不算功能完成。

本轮交付 PRD 的 M1 预览版，退出条件逐项记录。完整 Agent、跨轮映射和流式还原留在 M2。具体需求与退出条件见 [需求清单](PRD.md#需求清单) 和 [里程碑与验收](PRD.md#里程碑与验收)。
