# 0.1.8 用户验收记录

验收日期：2026-09-13。0.1.8 修复了 [0.1.7 实际重装验收](UAT-0.1.7.md) 中发现的 WorkBuddy 证书缓存问题。本记录区分自动化、安装包实际使用及尚无环境的场景。

## 修复内容

WorkBuddy AI 5.5.2 会跨重启复用 `system-ca-bundle.pem`。旧 CA 已从系统移除、新 CA 已获授权后，模型进程仍读取旧缓存，报 `UNABLE_TO_VERIFY_LEAF_SIGNATURE`，模型请求尚未进入网关正文检查。

0.1.8 在客户端关闭后，使这一派生缓存失效，再继续开启、完全移除或卸载流程。WorkBuddy 重新启动时自行读取系统证书生成缓存。缓存刷新失败时明确报错，保留连接与证书恢复资料，并重新打开原先运行的客户端。用户自行提供的附加 CA、模型、登录资料和其他设置不参与清理。

## 剩余边界

- 全新 macOS 系统用户尚无环境；独立应用数据目录与当前用户重装不替代该场景，是否后置仍待确认。
- 已实际验证授权未完成时保留原设置。用户回复前两次「没有点击取消或不确定」，因此前两次均只记为授权未完成；本轮补测也尚未取得明确取消证据，主动取消仍未验收。
- Windows 真机按用户决定后置，由用户从 GitHub Release 下载后自行运行；macOS Intel 本轮使用 Rosetta，不外推 Intel 硬件。
- 0.1.8 安装版的系统证书撤销、私钥清理及客户端缓存清理已有本轮实际证据；Windows 真正卸载的缓存清理顺序和失败恢复仍以自动化验证为据。
- 付费套餐、完整 Agent、跨轮映射、流式还原、正式签名和公证不在本轮通过声明内。

0.1.8 的本机文本、安装与恢复验收通过；M1 的全新用户环境和明确取消操作仍按上述边界记录，不标记为无条件全部验收完成。
